# claude-plugins

A marketplace of Claude Code plugins, one folder per plugin under `plugins/`.

## Pages a skill writes for the developer

Before creating or changing a page a skill writes for the developer to read in a browser
(`inventory.html`, `specs.html`, any new one), read `docs/page-design-rules.md` and follow
it: shared stylesheet, colours, header, tabs, outlines, side panel, corrections bar. A
page that needs something the rules do not cover adds the rule in the same change.
